# Metronos

> **Metro-nostos** — ギリシャ語の *métron*（μέτρον / はかるもの）＋ *nostos*（νόστος / 帰還）。
> メトロノーム（*métron* + *nómos* = 尺度の法）の後半を「帰ること」に差し替えた造語です。
> *nostos* は nostalgia と同じ語根で、オデュッセイアの主題＝「家へ帰る」を指します。

叩いた瞬間にテンポの主導権を握り、叩くのをやめると **設定したテンポへ自分で帰っていく** メトロノーム。

バンドでドラマーだけがクリックを聴いている状況を想定しています。ドラムが抜けるパートでは他のメンバーがクリックを聴けずズレていきますが、そこはドラマーがタップ（またはフットスイッチ）でリズムを先導。ドラムが復帰したらクリックに合わせて叩くだけで、テンポは自然に本来の値へ戻ります。

一般的な「タップテンポ」は設定するだけ、「テンポトレーナー」は決めたスケジュールで変化するだけ。**その場で握って、放すと帰る** という挙動がこのアプリの核です。

## 主な機能

### タップテンポ（テンポ先導）と自然復帰
- タップテンポパッド（または `T` / MIDIノート）を叩くと、その間隔でテンポを握る
- 停止中に叩くとテンポを測定（最初のタップから最後のタップまでの平均）。スタートでそのテンポから再生開始。測定タップでクリック音を鳴らすかは設定で切替（初期OFF）
- 復帰は**いまの拍の間隔を1拍ごとに数%ずつ**目標へ寄せる滑らかなもの
- 終盤は最低詰め量（0.5 BPM/拍）で有限拍のうちに着地。指数カーブの「いつまでも届かない」尾を防ぐ
- 初期状態（**自動復帰OFF**）では、叩いたテンポを握ったまま保持。**「ホームへ戻る」ボタン**（`R`）で復帰を開始。復帰中に押すと一時停止（今のテンポで保持）。長押し（0.6秒）または `H` で即座にホームへ（AirStep 等の長押しを送れないフットスイッチ向け）

### 標準メトロノーム機能
- テンポ 20–300（入力 / ±1 / ±5 / スライダー / タップ）、テンポ標語表示
- 拍子プリセット（2/4・3/4・4/4・5/4・6/8・7/8・3/8・拍なし）＋拍数増減
- **拍ごとのアクセント編集**（拍ドットをタップ：無音 → 通常 → ● → ◎）
- 細分化（4分・8分・3連・16分）、音色4種、音量

### セットリスト & セクション
- 曲ごとに設定を保存、⋮⋮ をドラッグで並べ替え（曲・セクションとも）、前後送り
- 曲の中に**セクション**（Aメロ／サビ等）を持てる＝**曲中テンポチェンジ**
- セクションはセットリストの曲の下に入れ子表示。行の ✎ でその場に編集フォームが開く（名前・BPM・拍子・リズム・小節数）。アクセントは拍ドットで
- セクションに小節数を設定 →「自動送り」で指定小節後に次セクションへ
- プロジェクトを **JSON ファイルに保存／ファイルから開く**（バックアップ・端末間移行）。テキストのコピペでも可
- localStorage に自動保存

### フットスイッチ（AirStep Lite 等）
Bluetooth HID キーボードとして接続します。初期のキー割り当ては以下。フットスイッチが送るキーが違う場合は、アプリ内「フットスイッチ（キー割り当て）」の「変更」→ 踏むだけで学習できます（受信したキーの生ログも表示）。

| キー | 機能 |
|---|---|
| `T` | タップテンポ（拍を踏む） |
| `Space` | 開始 / 停止 |
| `N` | 次セクション（曲末なら次の曲） |
| `P` | 前セクション（先頭なら前の曲） |
| `R` | ホームへ戻る（保持中→復帰開始、復帰中→一時停止、長押し→即復帰） |
| `H` | 即ホーム（復帰を待たずに戻る。長押しできないフットスイッチ用） |
| `A` | 自動復帰 ON/OFF（ONにすると叩くのをやめたら自動で戻る。初期OFF） |
| `S` | ステージ表示の切替 |

キーリピートは無視し、踏むと画面下端が光ってフィードバックします。

### MIDI 入力
Web MIDI 対応環境（Android Chrome / PC の Chrome 系）で、ドラムパッドの打撃をタップテンポに使えます。特定ノートだけに反応させる学習機能つき。

> iPhone / iPad は Web MIDI 非対応のため、MIDI 入力は使えません。**フットスイッチ（HID）はどの端末でも動作します。**

### iPad で音が出ないとき
- サイレントモード（コントロールセンターの🔔）が ON でも鳴るよう、再生セッションを `playback` に切り替えています（Safari 17+）
- 画面上の「オーディオ:」表示が「停止中」のままなら、スタートボタンを一度タップしてください（iOS はタッチ開始のイベントではオーディオを起こせないため）

### ステージ運用
- PWA（ホーム画面に追加でフルスクリーン起動・オフライン動作）
- 再生中は Wake Lock で画面スリープを防止
- ステージモード：全画面・高コントラストで BPM とパッドだけを特大表示（暗いステージ向け）
- iPad 横画面では左に大表示＋パッド、右に設定の2カラム表示

## 使い方

1. 目標テンポ（ホーム）・拍子・アクセントを設定
2. `スタート` で通常再生。タップテンポパッドを叩いてから `スタート` すると、叩いたテンポで開始
3. ドラムが抜けるパートは叩いて先導、戻ったら手を止める → テンポが自然にホームへ復帰

## 技術メモ

- 発音は Web Audio の**先読みスケジューラ**（25ms ごとに 130ms 先までを予約）で、`setTimeout` のジッターを回避
- 再生中のタップは「次の拍」として予約済みの自動拍を差し替える方式。タップをやめても拍が欠けない
- 直近に鳴った拍から 80ms 以内のタップは同じ拍として吸収し、二重発音（フラム）を防止
- テンポ推定は直近最大3区間の移動平均（2秒あくと測り直し）
- 復帰は BPM ではなく**間隔（秒）空間**で補間するため、速い／遅いテンポで体感が揃う
